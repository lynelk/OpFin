## Endpoints and operating rules

- GET `/api/admin/growth-readiness` requires a platform administrator. Other roles receive HTTP 403. The response returns no borrower or investor personal information and no customer financial permissions.
- `configuration_status: configured` is **never** proof of provider settlement, live funding, statutory authority or permitted investor participation; unknown values are represented as `null`, not `true`.
- `SignedMerchantEvidencePreflight` is an internal preflight helper. An untrusted `status:granted` field is **not** authoritative merchant consent.
- New productive-asset evidence is preserved in `asset_finance_cases.policy_snapshot.evidence_profile`, preventing later default-policy edits from silently changing requirements on an existing case.
- Existing customer/coaching access is preserved for all ages subject to product-level safeguarding and service eligibility. No arbitrary investor/loan-vintage wait has been added.

**Release interpretation:** deployment to the existing Railway production project is for iterative product testing; the six issues are not marked closed merely because code is deployed. External services and live money execution remain subject to their specific rules.
