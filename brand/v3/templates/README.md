# OpFin v3 Template Starters

These SVG starters establish controlled composition, spacing and colour for common OpFin outputs. They are not substitutes for final production files where an editable Office/Canva/Adobe source is required.

Included:
- `presentation-cover-16x9.svg`;
- `document-cover-a4.svg`;
- `letterhead-a4.svg`: legal footer fields must come from approved records, never invented;
- `one-pager-a4.svg`: the costs, risks and commitments panel is mandatory and must not be removed or shrunk;
- `social-square.svg`;
- `social-story-1080x1920.svg`: keep text inside the marked safe area;
- `link-preview-1200x630.svg`: Open Graph image, with titles kept to two lines;
- `email-signature.html`: text-first, with no images, tracking pixels or remote fonts;
- `partner-cobranding.svg`.

Bracketed text is a placeholder. Describe only what is live in the named channel. Never write "guaranteed" approval or returns.

Apply `../OPFIN_BRAND_SYSTEM_V3.md` for typography, claims, accessibility and co-branding rules. Preserve editable source in the production design system and export from that source rather than repeatedly editing flattened PNGs.
